结论

  • JDK HttpServer：100~2000 并发全部 100% 成功；5000 并发成功率 74.89%（1255 失败），p95=432ms / p99=441ms，RPS 峰值 5095。
  • NIO HttpServer：100~1000 并发 100% 成功；2000 并发 98.75%；5000 并发成功率骤降至 17.52%（p95=2.37s / p99=4.77s）——高并发下延迟急剧劣化，连接接纳能力弱于 jdk。
  • Netty HttpServer：所有档位 0% 成功（请求被拒绝/无响应）——当前 NettyHttpServer 实现存在 handler 层问题（HTTP 解析/响应路径），不能作为可用基准；延迟数据无意义，需先修复实现后再测。
  • 本机 12 核 Windows 环境为参考；串行压测（每次仅一个服务在跑）已避免资源争抢。
