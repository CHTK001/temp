## 四、结论

1. **两者在 5000 并发下均能扛住**：jdk 与 nio 的 5000 并发场景成功率均为 100%，无连接被拒、无超时失败。
2. **jdk 延迟更优**：各并发等级 p95/p99 显著低于 nio（约 2~6 倍差距），低并发下吞吐也更高（1000 并发峰值 19458 RPS vs nio 4171 RPS）。
3. **nio 吞吐随并发单调上升**：从 100 并发 1974 RPS 稳步爬升到 5000 并发 4171 RPS，未见饱和；jdk 在 1000 并发达到峰值后回落。
4. **nio 偶发失败**：100 并发 1 次、2000 并发 88 次失败（成功率仍 > 99.9%），失败集中在高延迟长尾（nio 最大延迟可达 1.4s），可能与 NIO 阻塞读 + 虚拟线程调度竞争有关，可作为后续优化方向。
5. 本报告为本机（12 核 Windows）参考数据；生产对比建议用 `docker-compose.benchmark.yml` 在专用压测机（172.16.0.40）上重跑后回填覆盖矩阵。
