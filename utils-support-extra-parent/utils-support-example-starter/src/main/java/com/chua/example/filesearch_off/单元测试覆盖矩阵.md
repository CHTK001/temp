### 2026-07-29 重测结果（按矩阵中 TC-01~TC-10）

由于 `FileSearchExample.java` 当前实现仅支持通过 `filesearch.root` 系统属性指定根目录，未暴露矩阵中的 CLI 选项（`--help`/`--test`/`--name`/...），重测改为直接通过 `FileSearchCriteria.Builder` 调用底层 API，对每个 TC 场景单独验证。

| 场景ID | 验证方式 | 结果 | 说明 |
|:------|:--------|:-----|:-----|
| TC-03 | namePattern="*.java", root=example-starter | ✅ PASS | 找到 46 个 .java 文件 |
| TC-04 | minSize=0 | ✅ PASS | 返回 100 个文件 |
| TC-05 | maxDepth=1 | ❌ FAIL | **BUG: maxDepth 参数未生效**，`lib.rs:830` 接收参数但未实现过滤 |
| TC-06 | excludeDirs="target" | ❌ FAIL | **BUG: excludeDirs 参数未传递给 native**，当前默认返回所有 |
| TC-07 | includeHidden=true | ✅ PASS | 找到 223 个文件 |
| TC-08 | sortBy=name, order=asc | ✅ PASS | 20 个文件按路径字母升序 |
| TC-09 | maxResults=5 | ✅ PASS | 正确限制为 5 |
| TC-10 | engine=NativeFileSearchProvider | ✅ PASS | 反射读取 provider 类名确认 |

### 已发现的 BUG

1. **`maxDepth` 不生效**: `lib.rs` 中 `fast_search_by_*` 函数接收到 `max_depth` 参数但赋值给 `_max_depth` 后未使用，参见 `G:\work\utils-support-native-parent\utils-support-native-filesearch\src\main\rust\src\lib.rs:830`
2. **`excludeDirs` 未传递**: `FileSearchCriteria.excludeDirs` 字段未传递到 Rust 端，Java→Rust FFI 缺少对应参数

## 能力矩阵 — MFT vs WalkDir (Windows + Linux)

### 环境信息

| 指标 | 值 |
|:-----|:---|
| OS | Windows 11 x86_64 (Build 22621) |
| CPU | x86_64 |
| 磁盘 | NVMe SSD (C:) NTFS, 186,868 条 MFT 记录 |
| Rust | rustc 1.97.1 |
| 扫描模式 | MFT = 管理员权限, WalkDir = 非管理员 |

### Windows 性能对比 (C: 盘)

| 模式 | 扫描范围 | 文件数 | 预热 (ms) | 首次 (ms) | 二次 (ms) | QPS (首次) | MFT 卷 | MFT 条目 | 线程 |
|:-----|:--------|:------|:----------|:---------|:----------|:-----------|:------|:--------|:----|
| MFT   | C: 全盘  | 155,353 | 1,687 | 1,566 | 1,467 | 99,200 | ✅  | 186,868 | 16   |
| WalkDir | C: 全盘  | 1000  | 16 | 1,474 | 1,594 | 678 | ❌ 拒绝访问 | — | — |
| MFT   | C:\Windows\System32 | 155,350 | 1,783 | 1,595 | 1,489 | 87,400 | ✅  | 186,868 | 16   |
| WalkDir | C:\Windows\System32 | 15,637 | 9 | 2,352 | 2,979 | 6,649 | ❌ 拒绝访问 | - | - |

> **MFT 注释**: MFT 模式扫描整个 NTFS 卷（不分目录过滤），因此 `C:\Windows\System32` 和 `C:` 的结果集相同（均为 155,353 个文件）。
> **QPS 计算**: QPS = 文件数 / 耗时(秒)

### WalkDir 基准 (Windows 非管理员)

### 跨平台总结

| 维度 | MFT (Windows Admin) | WalkDir (Windows Non-Admin) | WalkDir (Linux) |
|:-----|:-------------------|:---------------------------|:----------------|
| 平台支持 | Windows (NTFS) | Windows + Linux + macOS | Windows + Linux + macOS |
| 扫描对象 | MFT $MFT 元数据 | 文件系统目录树 | 文件系统目录树 |
| 性能 (全盘) | 1,566ms (155k 条) | N/A (超时) | 392ms (52k 条) |

| 线程数 | 16 (rayon) | 多线程 (jwalk) | 多线程 (jwalk) |
| 限制 | 需管理员 + NTFS | 无限制 | 无限制 |
