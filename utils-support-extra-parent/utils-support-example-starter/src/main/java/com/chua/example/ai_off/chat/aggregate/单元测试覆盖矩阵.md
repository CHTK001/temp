## 支持的路由策略

| 策略 | 说明 | 使用场景 |
|------|------|----------|
| failover | 故障转移，依次尝试每个客户端 | 高可用、主备切换 |
| round_robin | 轮询，依次选择客户端 | 负载均衡 |
| weighted | 加权轮转，按权重分配请求 | 差异化流量分配 |
| cost | 按成本路由，优先选择低成本 Provider | 成本控制 |
| latency | 按延迟路由，优先选择低延迟 Provider | 性能优化 |
| hybrid | 混合策略，支持多组条件路由 + 健康过滤 | 复杂路由场景 |

## 健康检查与自动切换配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enableHealthCheck` | boolean | false | 是否启动健康检查定时器 |
| `autoSwitchOnRateLimit` | boolean | false | 限流时自动切换到同模型其他客户端 |
| `autoSwitchOnQuotaExhausted` | boolean | false | 余额不足时自动切换 |
| `healthCheckIntervalMs` | long | 60000 | 健康检查轮询间隔（毫秒） |
| `maxRetriesOnSameModel` | int | 3 | 同名模型最大重试次数 |
