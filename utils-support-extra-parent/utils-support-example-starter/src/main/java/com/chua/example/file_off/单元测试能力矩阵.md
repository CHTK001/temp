## 3. 测试数据格式

所有格式使用统一表格数据：

| 姓名 | 年龄 | 城市 |
|------|------|------|
| 张三 | 25 | 北京 |
| 李四 | 30 | 上海 |

### 格式对应

| 格式 | 数据表示 |
|------|----------|
| csv | `姓名,年龄,城市` 首行表头 |
| json | `[["姓名","年龄","城市"],["张三",25,"北京"],["李四",30,"上海"]]` |
| xml | `<root><row><姓名>张三</姓名><年龄>25</年龄><城市>北京</城市></row>...</root>` |
| txt | `姓名\t年龄\t城市` 首行表头，TAB 分隔 |
| excel | Sheet 首行表头 |
| pdf | 表格形式文本 |
| docx | Word 表格，首行表头 |
| dbf | 字段名即表头 |

## 4. 回调接口

```java
public interface WriteCallback {
    default void onStart() {}
    default void onBeginWrite() {}
    default void onProgress(int cur, int total) {}
    void onComplete(boolean success);
}

public interface ReadCallback {
    default void onHeader(List<String> headers) {}
    void onBody(Object row);
    default void onComplete(long total) {}
}
```

## 5. 测试执行

```bash
# 全格式测试（切换 -Dfile.type）
mvn exec:java -Dexec.mainClass=com.chua.example.file.FileSystemExample -Dfile.type=csv
# 类型: csv, json, xml, txt, excel, pdf, docx

# 异步读取测试
mvn exec:java -Dexec.mainClass=com.chua.example.file.FileSystemAsyncReadExample -Dfile.type=csv

# Excel 合并单元格测试
mvn exec:java -Dexec.mainClass=com.chua.example.file.ExcelMergedCellExample
```
