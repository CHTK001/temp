## 架构图

```
JVM 进程
  ShmHttpServer (extends AbstractServer)
    ├─ doStart() → RustHttpBridge.start() → 加载 librust_http_bridge.so
    │   └─ Rust 内部启动 Tokio runtime + hyper 监听 0.0.0.0:8080
    ├─ 后台线程 dispatcher: shm poll → handleRequest → shm send response
    └─ urlMappingFilter 路由用户注册的 ServerHandler

Rust 动态库 (librust_http_bridge.so)
  hyper 每来一个请求 → 构造 envelope → 写 req shm
  oneshot 等对应 req_id 的响应 → 写回 HTTP 响应

共享内存 (libshmqueue.so)
  /rhb_req_<name>   容量 1024 × slot 64KB
  /rhb_resp_<name>
```
