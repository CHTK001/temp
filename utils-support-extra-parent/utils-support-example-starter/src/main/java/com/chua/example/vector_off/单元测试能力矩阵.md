## 4. 实现说明

| 实现 | type() 值 | 说明 |
|------|:--------:|------|
| MemoryVectorStorage | MEMORY | 基于 ConcurrentHashMap 的内存实现，默认可用 |
| JVectorVectorStorage | JVECTOR | 基于 JVector 4.x HNSW 图索引的本地向量检索，需 jvector 模块 |
| MilvusVectorStorage | MILVUS | 基于 Milvus SDK 2.6 的远程向量数据库，需 milvus 服务 |
