# DateTime 单元测试能力矩阵

> 针对 `com.chua.common.support.lang.date.DateTime` 与 `com.chua.common.support.lang.date.DateTimeRange` 的单元测试覆盖规划与状态跟踪。

## 1. 测试覆盖总览

| 类名 | 方法数 | 已覆盖 | 未覆盖 | 覆盖率 |
|------|--------|--------|--------|--------|

## 2. DateTime 单元测试场景

### 2.1 当前时间

| 方法 | 测试场景 | 覆盖状态 |
|------|----------|----------|
| `now()` | 返回非空 `LocalDateTime`，且与系统时间偏差在允许范围内 | ✅ |
| `now(ZoneId)` | 传入 `ZoneId.of("Asia/Shanghai")`，返回对应时区当前时间 | ✅ |
| `nowMillis()` | 返回正数毫秒时间戳，与 `System.currentTimeMillis()` 偏差在允许范围内 | ✅ |

### 2.2 解析

| 方法 | 测试场景 | 覆盖状态 |
|------|----------|----------|
| `parse(String)` | 默认格式 `yyyy-MM-dd HH:mm:ss` 解析成功 | ✅ |
| `parse(String)` | 默认格式 `yyyy-MM-ddTHH:mm:ss` 解析成功 | ✅ |
| `parse(String, String)` | 自定义格式 `yyyy-MM-dd` 解析成功 | ✅ |
| `parse(String, String)` | 自定义格式 `yyyy年MM月dd日 HH时mm分ss秒` 解析成功 | ✅ |
| `parse(long)` | 毫秒时间戳 `1705312830000L` 解析为正确 `LocalDateTime` | ✅ |
| `parse(Date)` | `Date` 对象正确转 `LocalDateTime` | ✅ |
| `parse(Date)` | `null` 参数返回当前时间（不抛异常） | ✅ |

### 2.3 格式化

| 方法 | 测试场景 | 覆盖状态 |
|------|----------|----------|
| `format(LocalDateTime)` | 默认格式 `yyyy-MM-dd HH:mm:ss` 输出非空字符串 | ✅ |
| `format(LocalDateTime, String)` | 自定义格式 `yyyy/MM/dd HH:mm:ss` 输出正确 | ✅ |
| `format(LocalDateTime, String)` | 中文格式 `yyyy年MM月dd日` 输出正确 | ✅ |
| `format(LocalDateTime)` | `null` 参数返回空字符串 | ✅ |
| `format(LocalDateTime, String)` | `null` 参数返回空字符串 | ✅ |

### 2.4 类型转换

| 方法 | 测试场景 | 覆盖状态 |
|------|----------|----------|
| `toMillis(LocalDateTime)` | 正确转换为毫秒时间戳，与 `Date.from(...).getTime()` 一致 | ✅ |
| `toMillis(LocalDateTime)` | `null` 参数返回 `0L` | ✅ |
| `toDate(LocalDateTime)` | 正确转换为 `Date`，且 `Date.getTime()` 与 `toMillis` 一致 | ✅ |
| `toDate(LocalDateTime)` | `null` 参数返回 `null` | ✅ |

### 2.5 时间计算

| 方法 | 测试场景 | 覆盖状态 |
|------|----------|----------|
| `plusYears(long)` | 正数年份递增，负数年份递减 | ✅ |
| `plusMonths(long)` | 正数月份递增，负数月份递减 | ✅ |
| `plusDays(long)` | 正数天数递增，负数天数递减 | ✅ |
| `plusHours(long)` | 正数小时递增，负数小时递减 | ✅ |
| `plusMinutes(long)` | 正数分钟递增，负数分钟递减 | ✅ |
| `plusSeconds(long)` | 正数秒数递增，负数秒数递减 | ✅ |
| `plus(LocalDateTime, long, DateUnit)` | `DateUnit.YEAR` / `MONTH` / `DAY` / `WEEK` / `HOUR` / `MINUTE` / `SECOND` / `MS` / `CUSTOM` 各单位正确计算 | ✅ |
| `plus(LocalDateTime, long, DateUnit)` | `dateTime` 为 `null` 时返回 `null` | ✅ |
| `plus(LocalDateTime, long, DateUnit)` | `unit` 为 `null` 时返回原 `dateTime` | ✅ |

### 2.6 时间差计算

| 方法 | 测试场景 | 覆盖状态 |

### 2.7 时间比较

| `isBetween(LocalDateTime, LocalDateTime, LocalDateTime)` | 任意参数为 `null` 返回 false | ✅ |
| `isToday(LocalDateTime)` | 传入今天返回 true | ✅ |

| `isToday(LocalDateTime)` | `null` 返回 false | ✅ |

### 2.8 时间区间

| 方法 | 测试场景 | 覆盖状态 |

## 3. DateTimeRange 单元测试场景

| 方法 | 测试场景 | 覆盖状态 |
|------|----------|----------|
| `getStartTime()` | 返回构造时传入的 startTime | ✅ |
| `getEndTime()` | 返回构造时传入的 endTime | ✅ |
| `isInRange()` | 当前系统时间在区间内返回 true | ✅ |
| `isInRange(LocalDateTime)` | 指定时间在区间内返回 true，在外返回 false | ✅ |
| `isOverlapping(DateTimeRange)` | 两区间重叠返回 true，不重叠返回 false | ✅ |
| `intersection(DateTimeRange)` | 有交集时返回正确交集区间 | ✅ |
| `intersection(DateTimeRange)` | 无交集时返回 `null` | ✅ |
| `union(DateTimeRange)` | 返回覆盖两区间的最小区间 | ✅ |
| `getDuration()` | 返回区间持续秒数，与 `Duration.between(start, end).getSeconds()` 一致 | ✅ |
| `构造器` | startTime 晚于 endTime 时抛 `IllegalArgumentException` | ✅ |

## 4. 边界与异常场景

| 场景 | 覆盖状态 |
|------|----------|
| `DateTime.parse(null)` — 不存在该重载，预期编译不通过 | ✅ |
| `DateTimeRange` startTime == endTime — 合法区间，isInRange 返回 true | ✅ |
| `DateTimeRange` 跨天/跨月/跨年区间 — isInRange / getDuration 正确 | ✅ |
| `DateTime.plus(..., DateUnit.CUSTOM)` — 当前等同于 `plusDays` | ✅ |
| 时区偏移导致日期变更 — `toEpochMilli` 与 `withZone` 时区一致性 | ✅ |

## 5. 测试数据与常量

以下常量建议在单元测试中复用，避免硬编码：

```java
// 时间常量
static final LocalDateTime FIXED_NOW = LocalDateTime.of(2024, 6, 15, 12, 0, 0);
static final LocalDateTime TIME_START = LocalDateTime.of(2024, 1, 1, 0, 0, 0);
static final LocalDateTime TIME_END   = LocalDateTime.of(2024, 12, 31, 23, 59, 59);
static final long EPOCH_MILLI = 1705312830000L;  // 2024-01-15 10:20:30 近似值

// 时区常量
static final ZoneId ZONE_SHANGHAI = ZoneId.of("Asia/Shanghai");
static final ZoneId ZONE_UTC = ZoneId.of("UTC");
```
