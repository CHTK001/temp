# 压缩包单元测试能力矩阵

> 针对 `com.chua.common.support.file.FileSystem` SPI 归档实现的读写测试覆盖。

## 1. 归档通用能力矩阵

横向：四种归档实现；纵向：通用功能。所有实现均支持以下能力。

| 能力 \ 实现 | zip | tar | zip4j | 7z |
|------------|:---:|:---:|:-----:|:--:|
| 链式写 write(Object) + finish | ✅ | ✅ | ✅ | ✅ |
| 同步读 read() | ✅ | ✅ | ✅ | ✅ |
| 文本读 asString() | ✅ | ✅ | ✅ | ✅ |
| 条目列表 listEntries() | ✅ | ✅ | ✅ | ✅ |
| 全部提取 extractAll(File) | ✅ | ✅ | ✅ | ✅ |
| 指定提取 extract(File, String...) | ✅ | ✅ | ✅ | ✅ |
| 嵌套路径匹配 extract("dir/sub") | ✅ | ✅ | ✅ | ✅ |
| 读条目 readEntry(String) | ✅ | ✅ | ✅ | ✅ |
| SPI 自动识别 FileSystem.auto(file) | ✅ | ✅ | ✅ | ✅ |

## 2. 实现特殊能力

### 2.1 ZipFileSystem（JDK 原生）

| 方法 | 说明 | 状态 |
|------|------|:----:|
| `@Spi({"zip"})` | SPI 注册名 | ✅ |
| `FileSystem.auto(".zip")` | 自动识别 | ✅ |

### 2.2 TarFileSystem（Apache Commons Compress）

| 方法 | 说明 | 状态 |
|------|------|:----:|
| `@Spi({"tar"})` | SPI 注册名 | ✅ |
| `FileSystem.auto(".tar")` | 自动识别 | ✅ |

### 2.3 Zip4jFileSystem（zip4j 密码）

| 方法 | 说明 | 状态 |
|------|------|:----:|
| `setPassword(String)` | 写/读密码保护 | a |
| `setCompressionLevel(CompressionLevel)` | 压缩级别 | a |
| `@Spi({"zip4j"})` | SPI 注册名 | ✅ |

### 2.4 SevenZFileSystem（Commons Compress 7z）

| 方法 | 说明 | 状态 |
|------|------|:----:|
| `@Spi({"7z"})` | SPI 注册名 | ✅ |
| `readEntry(String)` | 读取指定条目 | ✅ |

## 3. 测试执行

```bash
# 归档示例（手动切换 provider）
mvn exec:java -pl utils-support-extra-parent/utils-support-example-starter \
  -Dexec.mainClass=com.chua.example.file.ArchiveFileSystemExample \
  -Dfile.type=zip
# 可用类型: zip, tar, zip4j, 7z
```
