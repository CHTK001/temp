## 4. 执行方式

```bash
# 默认 DEFAULT + html,markdown,word 自检
mvn exec:java -pl utils-support-extra-parent/utils-support-example-starter \
  -Dexec.mainClass=com.chua.example.lang.document.DocumentExporterExample \
  -Dexec.args="--test"

# SWAGGER 模板
mvn exec:java -pl utils-support-extra-parent/utils-support-example-starter \
  -Dexec.mainClass=com.chua.example.lang.document.DocumentExporterExample \
  -Dexec.args="--template swagger --format html,markdown --test"

# AURORA 模板
mvn exec:java -pl utils-support-extra-parent/utils-support-example-starter \
  -Dexec.mainClass=com.chua.example.lang.document.DocumentExporterExample \
  -Dexec.args="--template aurora --format html,markdown --test"

# 指定输出目录
mvn exec:java -pl utils-support-extra-parent/utils-support-example-starter \
  -Dexec.mainClass=com.chua.example.lang.document.DocumentExporterExample \
  -Dexec.args="--out ./doc-out --template default --test"
```
