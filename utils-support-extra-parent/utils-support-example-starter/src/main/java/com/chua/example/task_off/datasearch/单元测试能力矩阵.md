## 7. 执行方式

```bash
# 综合自检（含所有套件）
java com.chua.example.task.datasearch.DataSearchExample --test

# 分套件
java com.chua.example.task.datasearch.UsageProviderExample --test
java com.chua.example.task.datasearch.UsageParserExample --test
java com.chua.example.task.datasearch.MusicSourceProviderExample --type demo --test
java com.chua.example.task.datasearch.VideoResourceProviderExample --type all --test
java com.chua.example.task.datasearch.SubtitleSearchProviderExample --type subhd --test
java com.chua.example.task.datasearch.DatasearchMcpExample --test
java com.chua.example.task.datasearch.DatasearchSkillExample --test

# 指定 UsageParser 类型
java com.chua.example.task.datasearch.UsageParserExample --type opencode --test
java com.chua.example.task.datasearch.UsageParserExample --type "codex++" --test

# 软件安装测试（会修改配置文件，谨慎使用）
java com.chua.example.task.datasearch.DataSearchExample --suite install --test
java com.chua.example.task.datasearch.DatasearchMcpExample --test --install
java com.chua.example.task.datasearch.DatasearchMcpExample --test --uninstall
```
