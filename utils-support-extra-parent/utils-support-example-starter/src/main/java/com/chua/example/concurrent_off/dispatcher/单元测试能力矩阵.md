## 4. 实现说明

| 实现 | SPI 名称 | 说明 |
|------|:------:|------|
| MemoryDispatcherProvider | memory | 基于 Reactor Sinks 的进程内 pub/sub，默认实现 |
| OracleDispatcherProvider | oracle | 模拟 Oracle LogMiner CDC 事件流，主题格式 oracle.cdc.<schema>.<table> |
| KafkaDispatcherProvider | kafka | 基于 Kafka consumer group 的跨进程 pub/sub |
| RabbitmqDispatcherProvider | rabbitmq | 基于 RabbitMQ 的 pub/sub |
| RedissonDispatcherProvider | redis | 基于 Redis Pub/Sub 的 pub/sub |
