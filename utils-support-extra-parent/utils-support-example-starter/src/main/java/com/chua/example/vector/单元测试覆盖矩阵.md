## 覆盖缺口（当前未覆盖，建议后续补充）

| 缺口ID | 能力点 | 说明 |
|:------|:--------|:-----|
| G-01 | 维度校验 | ✅ 已闭环：AbstractVectorStorage.add 与 update 均校验维度（示例未单列断言，但实现已内置，jvector update 在门面校验） |
| G-02 | 关闭后访问校验 | close() 后 search/add 应拒绝或抛异常，当前示例未验证 |
| G-03 | 重复 id 去重 | ✅ 已闭环：common-starter 新增 AbstractIdOrdinalStorage 抽象类统一 id↔序数映射与去重守卫，memory/jvector 三策略复用，行为一致（重复返回 false） |
| G-04 | DOT 算法 | 内置算法只覆盖 EUCLIDEAN/COSINE，DOT 未验证 |
| G-05 | MILVUS 后端 | 无 live 示例（需 Milvus 服务），旧矩阵标记"待测" |
| G-06 | add(Vector) / search(Vector, int) 重载 | 接口默认方法（委托给 String/float[] 版本），示例未直接调用验证 |
| G-07 | 关闭后 remove/update | close() 后调用 remove/update 会经 checkNotClosed 抛异常，未在示例中显式断言 |
