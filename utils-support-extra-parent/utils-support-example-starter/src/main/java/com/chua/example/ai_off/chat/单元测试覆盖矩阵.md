## 命令行参数

| 参数 | 简写 | 说明 |
|------|------|------|
| `--type` | `-t` | Provider 类型（openai / deepseek / zhipu 等） |
| `--api-key` | `-k` | API Key（优先于环境变量） |
| `--base-url` | `-b` | 自定义 API 地址 |
| `--model` | `-m` | 模型名称 |
| `--demo` | `-d` | 指定场景，逗号分隔（basic, stream, response, all） |
| `--help` | `-h` | 显示帮助 |
