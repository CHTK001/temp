## 命令矩阵

| 命令 | 行为 |
|:-----|:-----|
| `java WhisperAudioExample` | 走默认 provider (whisper-tiny) + 默认音频 + 同步 + 异步 |
| `java WhisperAudioExample --test` | 等价于默认 |
| `java WhisperAudioExample --file "C:/audio/clip.wav"` | 自定义音频路径 |
| `java WhisperAudioExample --provider local` | 仅跑 local 桩 |
| `java WhisperAudioExample --provider whisper --async` | 跑同步 + 异步 |
| `java WhisperAudioExample --help` | 打印帮助 |
